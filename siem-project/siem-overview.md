# SIEM Integration Project

## Objective

Extend the AWS Hybrid Cloud Security Lab by integrating a SIEM (Splunk) to enable centralized log analysis and threat detection.

## Architecture

AWS CloudTrail logs are stored in S3 and ingested into Splunk for analysis.

## Tools Used

- AWS CloudTrail
- Amazon S3
- Splunk Enterprise

## Outcome

Enabled visibility into AWS API activity and built detection queries to identify potential security events.
