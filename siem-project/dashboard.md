# Dashboard

## Process

- Created a Splunk dashboard to visualize AWS CloudTrail activity
- Added panels for key security use cases
- Used SPL queries to drive each visualization
- Leveraged parsed CloudTrail data using `spath` and `mvexpand`

## Panels

- Top AWS API Actions
- EC2 Activity
- Failed API Calls
- AWS Activity Over Time

## Result

Built a functional SIEM dashboard to monitor AWS activity and identify potential security-relevant events.

## Insight

Dashboards provide a centralized and visual way to monitor cloud environments, making it easier to detect anomalies and understand system behavior.

This dashboard demonstrates how AWS CloudTrail data can be transformed into actionable security insights using Splunk.
