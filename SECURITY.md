# Security Policy

## Supported scope

Security reports are accepted for the current `main` branch, including the log-sync automation, retained documentation, and sanitized evidence. Historical commits, deleted branches, forks, AWS services, Splunk, and other third-party components are outside the supported scope.

This is a completed, dismantled cloud-security lab. There is no live AWS account, host, endpoint, or credential associated with this repository. Do not attempt to access former resources, test identifiers found in Git history, or target infrastructure that you do not own and control.

## Reporting a vulnerability

Use GitHub's **Security > Advisories > Report a vulnerability** flow for this repository. Please include:

- the affected file and current commit;
- a concise description of the impact;
- safe, minimal reproduction steps; and
- a suggested remediation, if available.

Do not open a public issue for a suspected vulnerability, secret, account identifier, credential, or other sensitive data. Use only synthetic or redacted examples, avoid destructive testing, and stop if testing could affect any system or person outside your own environment.

Reports are reviewed on a best-effort basis. This portfolio project does not promise a response or remediation timeframe.
